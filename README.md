# Calmly

Веб-приложение для голосовой практики английского перед реальными ситуациями: собеседование, защита проекта, small talk, вопросы аудитории. Коуч на базе ИИ ведёт диалог, ничего не исправляет по ходу разговора, а в конце даёт разбор ошибок, лучшие фразы, индекс уверенности и темы для тренировки.

Тема проекта: *Leveraging AI Tools to Reduce Speaking Anxiety and Strengthen Communication Skills in Foreign Language Classrooms*.

## Что внутри первой версии

- 5 сценариев: собеседование на работу, собеседование в магистратуру (Leadership in Education), защита презентации или проекта, small talk, вопросы аудитории после доклада.
- Можно вставить свою тему или текст презентации, и коуч будет спрашивать именно по ней.
- Голос: распознавание и озвучка средствами браузера (бесплатно), запасной текстовый ввод.
- Против тревожности: дыхательное упражнение перед стартом, диалог без исправлений по ходу, кнопка «I am stuck» (идеи и фразы-подсказки), «Answer again» (переответить), мягкие напоминания.
- Разбор в конце: индекс уверенности, уровень (CEFR), ошибки с исправлениями, замена фраз на более естественные, улучшенная версия одного ответа, советы, темы для практики. Пояснения на английском или русском.
- Метрики, которые считаются на устройстве: темп речи, слова-паразиты, паузы, время до начала ответа.
- Без регистрации. На устройстве хранится только имя (localStorage), чаты не сохраняются.

Во второй версии: регистрация, история сессий и график уверенности (см. «Дальше»).

## Как это устроено

```
Браузер (Vue 3, без сборки)
  ├─ Web Speech API: голос → текст, текст → голос
  └─ POST /api/chat ──► Netlify Function «секретарь» ──► Groq (бесплатный ключ)
                         ключ хранится только здесь
```

Ключ API нельзя класть в код сайта: любой сможет его увидеть и потратить ваш лимит. Поэтому сайт обращается к функции на Netlify, а ключ лежит в её настройках. Схемы подробнее: `docs/ARCHITECTURE.md`.

Сборки нет сознательно: Vue подключается с CDN как ES-модуль, файлы работают как есть. Меньше шагов, нечему ломаться при деплое. При желании позже можно перенести на Vite и TypeScript.

## Быстрый старт на своём компьютере

Нужен только Node.js 18+ (ничего устанавливать через npm не надо).

1. Получите бесплатный ключ: https://console.groq.com → API Keys → Create. Карта не нужна.
2. Скопируйте `.env.example` в `.env` и вставьте ключ в `GROQ_API_KEY=`.
3. Запустите: `node scripts/dev-server.mjs`
4. Откройте http://localhost:8888 в **Chrome или Edge** (там работает распознавание речи).

Тесты: `node --test tests/*.test.mjs`

## Деплой на Netlify (бесплатно)

Способ A, через GitHub (рекомендую):

1. Создайте репозиторий на GitHub и загрузите туда папку проекта (`.env` не загружайте, он уже в `.gitignore`).
2. Netlify → Add new site → Import an existing project → выберите репозиторий. Настройки подтянутся из `netlify.toml`, менять ничего не нужно.
3. Site configuration → Environment variables → добавьте `GROQ_API_KEY` со своим ключом. Затем запустите повторный деплой (Deploys → Trigger deploy).
4. Откройте адрес сайта вида `https://имя.netlify.app`. По HTTPS микрофон работает и на телефоне.

Способ B, через командную строку:

```
npx netlify-cli login
npx netlify-cli deploy --prod
```

Перетаскивание папки в Netlify Drop я не проверял вместе с функциями, поэтому надёжными считаю два способа выше.

## Модели и лимиты

По умолчанию (меняется переменными окружения, см. `.env.example`):

| Назначение | Модель | Почему |
|---|---|---|
| Диалог | `llama-3.1-8b-instant` | быстрая, самые щедрые бесплатные лимиты |
| Разбор в конце | `llama-3.3-70b-versatile` | умнее на ошибках и советах |

Бесплатный тариф Groq ограничен по запросам и токенам в минуту и в день, и эти лимиты относятся ко всей организации, а не к отдельному пользователю. Точные цифры и список моделей меняются, смотрите их в консоли Groq на странице Limits. Если на показе или занятии будет много людей одновременно, поставьте `GROQ_MODEL_FEEDBACK=llama-3.1-8b-instant`: лимиты выше, разбор чуть проще.

Бесплатные функции Netlify работают не дольше 10 секунд. Разбор в конце делится на два параллельных запроса, чтобы укладываться в это время. Если всё же будут обрывы, используйте быструю модель для разбора, как описано выше.

## Ограничения, о которых стоит знать

- Распознавание речи лучше всего работает в Chrome и Edge (в том числе на Android). В Firefox голосового ввода нет, останется текст. Safari поддерживает его нестабильно.
- В Chrome и Edge звук обрабатывает сервис Google или Microsoft, а не наш сервер. Об этом написано внизу страницы.
- Браузеры обычно не записывают «um» и «uh», поэтому число слов-паразитов указано как минимум.
- Индекс уверенности и уровень CEFR это оценка ИИ по тексту и метрикам одной беседы, а не результат экзамена. В интерфейсе это сказано прямо.
- Защита от злоупотреблений простая: ограничение размера запросов и количества обращений с одного адреса (`RATE_LIMIT_PER_10MIN`, по умолчанию 120 за 10 минут). Для публичного запуска без присмотра этого может быть мало.

## Структура

```
public/                  сайт целиком
  index.html
  css/styles.css
  js/
    main.js, App.js      вход и переключение экранов
    components/          Welcome, Prep (дыхание), Session (диалог), Report (разбор)
    lib/                 speech (голос), api, metrics, scenarios, storage, vue (CDN)
netlify/
  functions/chat.mjs     «секретарь»: проверка входа, вызов Groq, разбор ответа
  lib/prompts.mjs        все инструкции для ИИ (только на сервере)
scripts/dev-server.mjs   локальный сервер без зависимостей
tests/                   тесты на node:test
docs/                    архитектура и описание проекта
```

## Офлайн-Vue

Если сайт должен работать без CDN, скачайте `vue.esm-browser.prod.js` (версия 3.5.13) в `public/vendor/` и поменяйте одну строку в `public/js/lib/vue.js`.
